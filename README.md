## 🚀 重点项目（GitHub 可查）
### 1. 港口堆场无人卡车调度与无冲突路径规划
- 首创性迁移 **Alternative Graph** 与 **Disjunctive Graph** 建模，精准刻画多卡车冲突场景
- 突破大规模问题求解瓶颈：设计「精确算法+启发式算法」混合方案（计划实现）
- 核心价值：直接为港口物流降本增效，可落地性强

### 2. 列生成+标签算法解决VRPSPD问题
- 构建考虑载货量与服务时间约束的VRP模型，子问题用Labeling算法实现状态动态更新
- 算法正确性100%验证：与Gurobi求解结果对比误差<1%，并实现迭代过程可视化看板
- 技术亮点：轻量化代码架构，支持不同场景下的参数快速调整

### 3. 多AGV无冲突路径规划（含订单分配）
- 优化经典CBS算法：新增「最短路径预计算+环境预感知+上下界剪枝+最小冲突启发」4大加速算子，有效提升求解速度
- 创新设计单阶段ALNS算法，将冲突解决策略嵌入破坏/修复算子，随机算例表现优于传统混合算法
