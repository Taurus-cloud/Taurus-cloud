## 重点项目

### 多 AGV 协同调度与无冲突路径规划

面向自动化码头多 AGV 并行运输场景的联合任务调度与无冲突路径规划研究。

- **问题：** 联合决定任务分配、执行顺序与候选作业节点，并处理多车路径时空冲突。
- **建模：** 使用混合整数规划构建初始调度；目标按优先级兼顾任务延误与车辆返场相关指标。
- **智能优化：** 使用 ALNS 进行大规模初始调度，包含随机移除、延迟任务移除、关联移除与最佳插入修复。
- **冲突消解：** 基于预约链、资源时间线与合法等待节点处理节点冲突、同向边冲突和对向边冲突。
- **局部改进：** 基于等待、延误、节点热点和作业间隙反馈生成候选；每个候选均重新经过完整冲突消解与硬约束校验。
- **工程实现：** 提供 MIP / ALNS 双求解模式、实验入口、统一评价、图表与可视化生成模块及回归测试。

**方法：** MIP · ALNS · Reservation Chain · Conflict-Free Routing · Feedback-Driven Local Improvement

该研究仓库目前为私有状态，正在进行数据与演示资产的公开安全审查。

### [CVRPSPD 列生成求解器](https://github.com/Taurus-cloud/CVRPSPD_CG)

同时取送货车辆路径问题（Vehicle Routing Problem with Simultaneous Pickup and Delivery）的列生成实现。

- 构建直接 Gurobi 模型，用于小规模实例的参考求解。
- 以受限主问题维护路径池、客户覆盖约束与车辆数量约束。
- 以基于标号的定价子问题生成负化简成本路径，并通过支配规则剪枝。
- 输出路径图、列生成迭代动画、LP 模型与运行日志。

**方法：** Column Generation · Restricted Master Problem · Pricing Problem · Labeling · Gurobi

### [TSP 求解器对比](https://github.com/Taurus-cloud/TSP_SA_Gurobi)

旅行商问题的精确算法与元启发式算法对比实现。

- 分别使用 Gurobi 和 SCIP 构建基于 MTZ 子回路消除约束的精确模型。
- 实现以两城市/三城市交换为邻域的模拟退火算法。
- 对相同坐标实例输出路径长度、运行时间、目标值与可用的 MIP Gap，并生成路线对比图。

**方法：** MIP · Gurobi · SCIP · Simulated Annealing
